# amity-BS605 — Cognitive Analytics and Social Skills for Professional

Standalone study pack for **BS605** (Amity University Online).

This repo is **only** for BS605. It does not replace or overwrite the PFE701 / main AMITY materials.

## Open locally
Open `index.html` in a browser.

## Online (GitHub Pages)
https://mpfahad.github.io/amity-BS605-Cognitive-Analytics/

## Cross-device progress
Use the **Sync progress** panel (same private sync code on phone and PC).

One-time backend setup: [SETUP-SYNC.md](SETUP-SYNC.md) (free Supabase project + paste URL/anon key into `config.js`).

## Rebuild
```bash
python build_study_pages.py
```
